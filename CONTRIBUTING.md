# Contributing

Bug reports, feature ideas and results from new basins are welcome via GitHub issues.

1. Fork and clone the repository, then `pip install -e ".[dev]"`.
2. Add a test for your change in `tests/` and run `pytest`.
3. Open a pull request describing what changed and why.

If the tool fails on your data, please include the error message and the first few rows of each file
(you can replace values with made-up numbers).
